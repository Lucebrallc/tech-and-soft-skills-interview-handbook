## 🧠 Part 1: The Behavioral & Executive Advantage (TJ Walker Method)

Most senior engineering candidates fail not on code, but on **communication, presence, and behavioral framing**.

### 1. The Executive STAR Framework
When asked *"Tell me about a time a project failed or missed a deadline"*:
- **Situation (15%):** Set the stage concisely without blaming team members.
- **Task (15%):** Define your specific responsibility.
- **Action (50%):** Detail the exact technical decisions, stakeholder escalations, and trade-offs you executed.
- **Result (20%):** Quantify the outcome (e.g., *"Saved 40% compute cost, recovered uptime to 99.95%, instituted CI/CD safeguards"*).

### 2. High-Stakes Salary & Equity Negotiation
- Never give the first number; anchor around total compensation packages.
- Ask: *"What is the approved budget range for an engineer operating at this impact level?"*
- Frame counter-offers around your verified track record and certifications.

## 💻 Part 2: Technical & Architecture Screenings

### Common System Design Archetypes
1. **Design a Global Distributed Rate Limiter:**
   - Token Bucket vs Leaky Bucket vs Sliding Window Log.
   - Redis cluster with Lua scripts for atomic decrement.
2. **Design an Event-Driven Notification Engine:**
   - Kafka / RabbitMQ partitioned by user ID.
   - Idempotency keys to prevent duplicate emails/SMS.
3. **Design a Resilient IoT Ingestion Pipeline:**
   - MQTT brokers, time-series databases (TimescaleDB / InfluxDB).
   - Downsampling and edge aggregation.
